# 幾歳

A landscape stage read-through for two players. Yae reads the narration as well as her dialogue. Reiji reads his dialogue. Chitose's recollection portrait is in `art/`. The script assigns her no lines.

From the toolkit root, run `npm ci`, then `npm run harness -w sample-ikutoshi`. Open the harness URL printed in the terminal. Run `npm run build -w sample-ikutoshi` to build the work.

`read-through.layout.json` sets the stage coordinates and art names. `public/assets/` holds the images used by the stage and the manifest. `script/original.txt` preserves the supplied script. The repository's code license does not grant rights to the supplied script.
