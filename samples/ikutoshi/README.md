# 幾歳 — Taisho-Roman sample

A two-seat sample using the toolkit's `readThroughLogic` and `StageReadThrough`.

This branch contains the runnable source skeleton and an **opening excerpt only**. The complete 366-line PDF-derived script, generated Taisho mansion background, Yae/Reiji standing art, icons, and UI WebP assets are supplied in `ikutoshi-toolkit-sample.zip` in the project handoff. Copy the archive's `samples/ikutoshi` folder over this directory before evaluating the complete work.

From the repository root:

```sh
npm install
npm run harness -w sample-ikutoshi
npm run typecheck -w sample-ikutoshi
npm run build -w sample-ikutoshi
```

The script follows the source's dialogue, with the unnamed man and woman displayed as Reiji and Yae; the Yae seat also reads stage narration. No branching choices have been invented. Validate the source text, rights, layout, and UZU certification before publishing.
