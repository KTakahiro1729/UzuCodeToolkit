# 画像部品の発注書：read-through（landscape）

この発注書は、画面に使う画像部品を作るためのものです。上から順に読み、「部品一覧」の画像を、1回の生成で1枚ずつ、それぞれ別に作ってください。場面全体の絵を作って部品を切り出してはいけません（切り出すと解像度が落ちます）。「場面ごとの見本」は、部品がどこに置かれるかの説明で、描く対象ではありません。

## 【世界観】

（ここに作品の世界観を書く：舞台、時代、色味、素材感、雰囲気。例：大正時代の洋館の応接間。漆黒と真鍮の色、和紙と革の質感、静かで少し寂しい雰囲気）

## 共通のルール

- 画像の中に文字・数字・記号・ロゴを描かない。文字はあとでコードが載せる。
- 部品は1枚ずつ、「部品一覧」の大きさで直接生成する。場面全体の絵や、複数の部品を1枚に並べた絵を作って切り出さない。人物を背景に描き込まない（人物は立ち絵の部品として別に作る）。
- 部品名、寸法、位置の目印線、注釈など、説明のための書き込みを絵に残さない。
- 画面いっぱいの背景以外は、背景を透明にする（アルファ付き）。
- 「何も置かない縁」と、UZUが重ねて描く領域には、絵を置かない。
- 同じファイル名の部品は同じ画像を使い回す。1枚だけ作る。
- アルファ（透過）付きの PNG で受け取る。ファイル名の .webp は組み込み後の名前で、PNG からの変換は後で行う。大きさは「部品一覧」のpx。
- 作った画像は CC0 1.0 として同梱する。既存の作品やキャラクターに似せない。
- リポジトリにあるデザイン方針の文書は、機能面の決まりであり、この発注書の対象外。見た目（配色・質感・装飾・雰囲気）は、この発注書と【世界観】だけを手がかりに自由に決めてよい。
