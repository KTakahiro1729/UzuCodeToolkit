# The design policy has no rule about the look

The mood of a screen (colours, world, materials, effects) is the work's. The design policy keeps only what helps players see what to do: contrast (WCAG AA, also for text set on a work's images), no colour, size or weight that competes with the focus, and the roles that fill and edge carry. The rule "no gradients, edge fades, shadows or glows" was a statement about the look, so it is removed from `docs/design.md` and `docs/design/read-through.md`. The toolkit's own default look stays plain, because its tokens are neutral, not because a rule forbids more.

Not touched: the typefaces in "Type" (they come with a legibility reason) and the image brief's 【世界観】 section, which asks the author for the mood.
