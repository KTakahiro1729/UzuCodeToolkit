# Chat-style screen with icons

Lines appear as chat bubbles with the speaker's icon; your role's lines on the right, the other role's on the left. Icons are assumed to exist (`public/assets/icon-<role>.webp`, also used by the manifest's character select); the current files are placeholders: Noto Color Emoji glyphs (🗡️ for 勇, 🐙 for 百) rendered once to webp, so they look the same on every device.
