# The footer is the main action area

Every screen's main actions (advance, next, the handout's time, extension and done, back to the list) sit centred in a footer along the bottom edge, the same place in every phase. In a work of more than one phase it also holds, quieter, the phase list and, once the handout phase is over, the handouts; each opens as a sheet over the current screen for that player alone, and a phase change closes it. Landscape keeps it to one row.
