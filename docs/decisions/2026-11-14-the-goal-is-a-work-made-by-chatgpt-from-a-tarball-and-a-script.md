# The goal: a creator gives ChatGPT the toolkit tarball URL and a script, and gets a UZU Code work from lobby to debrief

- **Scope now:** read-through works only. Other kinds (games and so on) come later, one at a time.
- **Target AI:** ChatGPT only for now. Do not write instructions or docs for other AIs yet.
- **Audience:** other creators too, not only the owner. The tarball and its docs must work for someone who has never seen this repository.
- **Split:** function lives in the toolkit; look and atmosphere (colours, world, art, sound) live in the work. Assets are generated by AI.
- **Licenses:** MIT for the code and CC0 1.0 for AI-generated assets apply only to what this project ships. A creator licenses their own work as they choose.
- **Minimal:** a work ships nothing it does not use (YAGNI).
- **Reference work:** InterstellarBoardGame is the sample of a work built on the toolkit.

Not taken: supporting several AIs at once, and covering games before the read-through path is solid.
