# A half-made picture set fails the static check

Pictures stay optional: a work with none is drawn from colour tokens. Once a work ships any picture its layout names, the rest of the set (every `image` of the layout, `-mine` for a part that takes your colour, `stand-<cast id>` for each cast entry that is not a direction) must be there, or `tools/check/static.mjs` reports `picture-missing` as an error. The reason is the runs of an image-generating agent: it made the background and the frame, skipped the rest, and reported the work done; a step it can skip is a step a script has to hold. The agent already runs `static.mjs`, so the gate sits there; it reads only the first bytes of each WebP and needs no image library or browser. Size ratio and missing alpha are warnings (style), and the full-screen background is not checked for ratio, since it is cropped to cover. Taking screenshots in the agent's sandbox is not part of the gate: its Chromium did not render in two tries.
