# Handout (HO) phase

Every player reads the shared text and their own part's text, fills in the settings their part asks for, and taps done; the phase ends when everyone is done. Done needs every setting filled in, except those the data marks `optional`. A player can take done back while the phase lasts, which unlocks their settings and the extension button again. Settings stay in the phase state by part and setting ID, so later phases can use them. Labels come from the work's data; the screen's own labels from `strings.json`.
