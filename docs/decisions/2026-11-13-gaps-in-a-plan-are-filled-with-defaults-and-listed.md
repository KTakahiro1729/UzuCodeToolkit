# Gaps in a plan are filled with defaults, and the list of what was chosen is returned

Where a plan leaves something open (a phase's length, who moves the game on, a screen's layout, a string), the toolkit fills it with a sound default and does not stop to ask. It then returns the list of every default it chose, so the author can read it once and change what they want. A default the author does not change stays; a choice the author makes in the plan always wins.

Why: the author's work is the plan, not the questions. A list of choices is quicker to correct than a series of prompts, and nothing is hidden.

Not taken: asking for each gap before building; filling gaps silently.

Status: this states the direction. The list is not built yet; build it when a plan reader is built (see the-toolkit-takes-what-prevents-an-error-no-eye-can-see).
