# The handout's tabs spread over columns where there is room, and the band gives way on small screens

A handout takes a column per tab (about 18em each, up to 3) with the rest as tabs in the last, counted on its own width, so beside the screen it has fewer. The narrowest screen supported is 320px wide: under 380px the phase has a row above the players; names and long phase names end in an ellipsis. Under 480px tall the band's icons and names sit side by side and the band is shorter. Details in `docs/design.md`.
