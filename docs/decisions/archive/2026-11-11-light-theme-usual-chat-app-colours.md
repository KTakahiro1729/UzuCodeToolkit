# Light theme, usual chat-app colours

Soft grey page (not pure white); the current line is white, or a calm blue when it is yours; read lines sit on quieter bubbles with full text contrast. Tokens live in `samples/hundred-arms/src/theme.css`; screens use those variables, never raw colours. Every text colour meets WCAG AA (4.5:1); no opacity fades on resting states.
