# The deck's corner index is a quarter of the card's width, and cards are 4em wide or more

A third left only 45% of the height for the pips and figures, which shrank and looked sparse (owner: spread them out). A quarter at 4em is still 16px. `enlarge-index.mjs` builds the deck with rank 60 and suit 42 units high; works using `PlayingCard` set `width` to 4 or more.
